# 气象分析算法与阈值参考

本文档供分析报告模式（analyze）的 LLM 参考，描述各指标算法、判断阈值与天气系统识别规则。

## 一、气压梯度（3小时变压）

**算法**：`pressure_msl[t] - pressure_msl[t-3]`（hPa/3h）

**阈值与判读**：

| 变压值 (hPa/3h) | 含义 |
|-----------------|------|
| > +3 | 强升压，高压系统快速移入，天气转好 |
| +1 ~ +3 | 升压，高压趋近 |
| -1 ~ +1 | 气压平稳，天气稳定 |
| -3 ~ -1 | 降压，低压趋近，天气转差 |
| < -3 | 强降压，低压系统快速移入或锋面过境，天气剧烈变化 |

**应用**：连续降压 + 风增大 + 云增厚 = 锋面/低压系统 approaching；连续升压 = 高压控制建立。

## 二、K指数（对流稳定性）

**算法**：`K = (T850 - T500) + Td850 - (T700 - Td700)`

其中 Td（露点）由马格努斯公式从温度+相对湿度计算：`Td = (b·γ)/(a-γ)`，`γ = ln(RH/100) + a·T/(b+T)`，a=17.625, b=243.04。

**阈值**：

| K值 | 稳定性 | 对流潜势 |
|-----|--------|----------|
| < 20 | 稳定 | 对流潜势低 |
| 20-30 | 中等 | 有限对流可能 |
| 30-40 | 中等不稳定 | 雷暴可能 |
| > 40 | 很不稳定 | 强对流潜势（雷暴/短时强降水） |

## 三、Showalter指数（雷暴潜势）

**算法**（简化近似）：`SI ≈ 20 - 0.5 × K`

> 注：标准 Showalter 指数需抬升气块从 850hPa 沿干绝热至凝结高度，再沿湿绝热至 500hPa，与环境温度比较。此处的简化近似基于 K 指数线性映射，仅供趋势判断。

**阈值**：

| SI值 | 含义 |
|------|------|
| > +3 | 稳定 |
| 0 ~ +3 | 轻度不稳定 |
| -3 ~ 0 | 中度不稳定，雷暴可能 |
| < -3 | 强不稳定，强雷暴潜势 |

## 四、CAPE近似（对流有效位能）

**算法**（简化）：`CAPE ≈ max(0, (K-25) × 80)` J/kg

> 注：标准 CAPE 需完整层结曲线积分。此近似基于 K 指数经验关系。

**阈值**：

| CAPE (J/kg) | 含义 |
|-------------|------|
| 0-1000 | 弱对流 |
| 1000-2500 | 中等对流 |
| 2500-4000 | 强对流 |
| > 4000 | 极强对流 |

## 五、风切变（850-200hPa）

**算法**：850hPa 与 200hPa 风矢量差的大小。

`shear = √[(u200-u850)² + (v200-v850)²]`

u,v 由风速风向转换：`u = -speed·sin(dir)`, `v = -speed·cos(dir)`

**阈值**：

| 切变 (m/s) | 含义 |
|-----------|------|
| < 10 | 弱切变，对流组织性差 |
| 10-20 | 中等切变 |
| > 20 | 强切变，组织化对流环境（超级单体可能） |

## 六、降水分级

**算法**：24小时累积降水量。不同地区分级标准不同，脚本默认采用中国气象标准，可按需调整阈值。

### 中国气象标准（脚本默认）

| 24h累积 (mm) | 等级 |
|--------------|------|
| < 0.1 | 无降水 |
| 0.1-10 | 小雨 |
| 10-25 | 中雨 |
| 25-50 | 大雨 |
| 50-100 | 暴雨 |
| > 100 | 大暴雨 |

### 国际通用参考（NWS 雨率分级）

| 雨率 (mm/h) | 等级 |
|-------------|------|
| < 2.5 | 轻雨 (light) |
| 2.5-7.6 | 中雨 (moderate) |
| 7.6-50 | 大雨 (heavy) |
| > 50 | 暴雨 (violent) |

> 分析报告时按用户所在地区选择合适的分级标准。中国地区用中国标准，其他地区可用 NWS 参考或当地标准。

## 七、温度距平

**算法**：`anomaly = T[t] - mean(T)`

与序列均值的偏差，正值偏暖，负值偏冷。

| 距平 (°C) | 含义 |
|-----------|------|
| > +3 | 显著偏暖 |
| +1 ~ +3 | 偏暖 |
| -1 ~ +1 | 正常 |
| -3 ~ -1 | 偏冷 |
| < -3 | 显著偏冷 |

## 八、天气系统倾向评分

**算法**：综合 3h变压 + 10m风速 + 总云量 的评分。

- 气压变压：>+1 加2分，>+0.5 加1分，<-1 减2分，<-0.5 减1分
- 风速 >8 m/s：减1分
- 云量 >80%：减1分；<30%：加1分

**判读**：

| 评分 | 倾向 |
|------|------|
| ≥ 2 | 高压控制（晴好） |
| 1 | 高压趋近 |
| 0 | 稳定 |
| -1 | 低压趋近 |
| ≤ -2 | 低压影响（转差） |

## 九、天气系统识别规则（供 LLM 推理）

### 高压系统
- 海平面气压 > 1020 hPa 且稳定/上升
- 风弱，云少
- 天气：晴朗、稳定

### 低压系统
- 海平面气压 < 1000 hPa 且下降
- 风增大，云增厚
- 天气：多云/降水、不稳定

### 锋面过境
- 3h变压剧烈（通常 < -3 hPa/3h）
- 风向突变
- 温度骤变
- 降水增强

### 冷锋
- 锋后气压上升、温度下降、风向转北
- 锋前可能有雷阵雨

### 暖锋
- 锋后温度上升、气压缓降
- 层状云系，连续性降水

### 热带气旋/台风
- 气压极低（< 980 hPa）且急剧波动
- 强风（> 17 m/s）
- 强降水

## 十、LLM 分析报告要求

1. **基于指标推理**：引用具体指标数值支撑结论，不做无依据判断
2. **区分结论与推断**：数据支撑的标"数据表明"，推断的标"推测"
3. **标注不确定性**：简化算法（Showalter/CAPE 近似）的结果需注明"近似值"
4. **时间维度**：关注指标随时间的变化趋势，而非单点值
5. **综合判断**：单一指标不足以定性，需多指标交叉验证（如 K指数高 + CAPE高 + 风切变强 = 强对流潜势）
6. **通俗解释**：专业结论后附一句话通俗解释
