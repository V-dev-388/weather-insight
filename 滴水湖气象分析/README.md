# 滴水湖片区气象分析系统

每半小时自动分析上海临港·滴水湖（约 30.90°N, 121.92°E）气象状况，
生成「当前实况 + 后半小时预测 + 后 8 小时预测」报告，历史报告全部存档不覆盖。

## 目录结构

```
滴水湖气象分析/
├── README.md                  # 本说明
├── scripts/
│   └── analyze_dishuihu.py    # 分析主脚本（可独立运行）
└── reports/
    ├── README.md              # 报告索引（最新标记 + 历史表格）
    ├── latest.html            # 软链，始终指向最新 HTML 报告
    ├── cron.log               # 定时任务运行日志
    └── YYYY-MM-DD/            # 按日期分目录
        └── REPORT_YYYYMMDD_HHMM.html   # 带时间戳的自包含 HTML 报告（含 SVG 气象图），不覆盖
```

## 报告内容

每份报告为**自包含 HTML**（内联 CSS + 内联 SVG 图表，无需联网即可在浏览器打开），包含：
1. **当前实况卡片**：天气、气温、体感、湿度、降水、风速、风向、气压
2. **后半小时预测**：基于当前→下一整点的线性外推
3. **后 8 小时预测**：11:00–18:00 逐时天气/气温/湿度/降水概率/风力/气压 表格
4. **气象图（SVG）**：气温变化折线图、降水概率柱状图、风速变化折线图、当前风向标
5. **趋势研判 + 综合建议**：降水/大风/气温/气压分析，带伞/防风/防暑提示

> 图表零依赖纯手写 SVG，离线可用；无需 matplotlib/PIL，也无外网 CDN。

## 如何查看最新报告

```bash
cat reports/latest.md
# 或直接打开索引
cat reports/README.md
```

## 定时调度

**方式一：会话托管的自动调度（已生效）**
- 周期 **每 30 分钟**一次，会话结束后任务即终止
- 自动调度 **3 天后自动过期**，可随时取消

**方式二：手动运行（随时可触发一次）**
```bash
python3 scripts/analyze_dishuihu.py
```

## 数据来源

[Open-Meteo](https://open-meteo.com/) 公开数值天气预报 API，无需密钥。
若 `urllib` 因 SSL 证书问题失败，脚本自动回退到 `curl`（已验证可用）。

## 取消定时任务

```bash
crontab -l | grep -v "analyze_dishuihu.py" | crontab -
```
